The problem

$1.62M is about to be forfeited — and nobody can see it

  • Co-op marketing funds for AMER East FY26 are sitting ~45% unused, ~138 days from expiry.
  • The answer lives across 4 disconnected systems: SFDC, SAP/ERP, the dealer portal, and a pile of policy PDFs.
  • Maya (Channel Marketing Manager) needs numbers, policy, and the ability to act — today that's three tools and a week.

Solution

One agent, three modalities, one platform

  • Genie — quantitative metrics over governed UC Metric Views.
  • Agent Bricks KA — policy & how-to, with enforced citations.
  • Action tools — approve claims, send nudges, save views — backed by Lakebase.
  • A Supervisor MAS routes each turn; MLflow traces every one.

Lakebase writes are reverse-ETL'd back to Unity Catalog, so the next agent turn sees the action that was just taken.

Phase 1 · Data foundation

Medallion on Unity Catalog

  • Bronze — 8 raw feeds (claims, ERP order lines, registrations, allocations + 4 reference tables).
  • Silver — conformed, deduped, typed.
  • Gold — 4 facts incl. fact_coop_utilization_daily with precomputed forfeiture risk.
  • 5 UC Metric Views — one governed definition of utilization_rate shared by Genie, the app, and Finance.

~10K claims · ~625K order lines · hero cohort sums to $1.62M unused, by construction.

Phase 3 · Quantitative

Genie answers the “how much”

  • Two spaces: Co-op Utilization & Risk and Marketing Effectiveness & ROI.
  • Natural language → SQL over the metric views, with the SQL on display.
  • Hero turn: “Which region has the most unused co-op funds at risk this fiscal year?” → AMER East, $1.62M.
Phase 4 · Qualitative

The Knowledge Assistant answers the “how”

  • Agent Bricks KA indexed over an 8-document corpus: handbook, eligibility, claim playbook, brand spec, regional addenda, forfeiture policy, FAQ.
  • Every answer carries [KA-XXX-### §section] citations — no policy claim without a source.
  • Audience- and region-scoped so dealers and internal staff see the right guidance.
Phase 6 · Orchestration + write-back

A supervisor routes; actions write back

  • Hybrid Supervisor MAS (compass-supervisor) with 3 sub-agents: util/risk analyst, marketing analyst, handbook expert.
  • An embedded action gate handles approve-claim, send-nudge, save-view — each as a preview card the user confirms before any write.
  • Confirms write to Lakebase; the change flows back to UC for the next turn.
Phase 7 · Databricks Apps

It all ships as one app

  • React + FastAPI on Databricks Apps — two-pane chat plus an Approvals / Nudges / Saved Views workbench.
  • Persona switcher (Maya / Eliot / Priya / Jordan / Renske) with role-specific KPI home tiles.
  • Tabbed chat: Auto (MAS routing), Genie Utilization, Genie Marketing, KA Handbook.
